Politique de Confidentialité

Dernière mise à jour : 2 mai 2026 (v1.1.0)

1. Introduction

Cortex IA ("l'Application") est développée par Antoine Drai. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application.

2. Données collectées

L'Application accède aux services Google suivants via votre compte Google, uniquement après votre consentement explicite :

  • Gmail : Lecture, envoi et suppression d'emails à votre demande.
  • Google Calendar : Consultation, création et suppression d'événements.
  • Google Docs : Lecture, création et édition de documents.
  • Google Drive : Accès aux fichiers créés par l'application uniquement.

Nous collectons également :

  • Votre nom et adresse email (via Google Sign-In) pour personnaliser l'expérience.
  • Les notifications de votre appareil (si vous activez le briefing matinal).

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Répondre à vos commandes et requêtes adressées à l'assistant Jarvis.
  • Générer votre briefing matinal personnalisé.
  • Prioriser vos tâches via le module d'intelligence artificielle.

4. Stockage et sécurité

Vos données personnelles (conversations, tâches) sont stockées localement sur votre appareil. Aucune donnée n'est conservée sur nos serveurs après le traitement de votre requête. Les jetons d'accès Google sont stockés de manière sécurisée dans les SharedPreferences chiffrées de votre appareil.

5. Partage des données

Nous ne vendons, ne louons et ne partageons aucune de vos données personnelles avec des tiers. Vos requêtes sont traitées via l'API Google Gemini pour générer les réponses de l'assistant.

6. Services tiers

L'Application utilise les services suivants :

  • Google Gemini API : Pour le traitement du langage naturel.
  • Google Workspace APIs : Pour l'accès à Gmail, Calendar et Docs.
  • Serper API : Pour les recherches web.

7. Vos droits

Vous pouvez à tout moment :

  • Révoquer l'accès de l'application à votre compte Google via les paramètres de votre compte Google.
  • Supprimer toutes vos données locales en désinstallant l'application.
  • Demander la suppression de vos données en nous contactant.

8. Contact

Pour toute question relative à cette politique de confidentialité, vous pouvez nous contacter à : cortexia.app@gmail.com

9. Modifications

Nous nous réservons le droit de modifier cette politique à tout moment. Toute modification sera publiée sur cette page avec une date de mise à jour.
